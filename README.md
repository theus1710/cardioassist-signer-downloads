# Assinador CardioAssist

Repositório público dos instaladores do Assinador CardioAssist para Windows e macOS.

## Downloads

Use a seção [Releases](https://github.com/theus1710/cardioassist-signer-downloads/releases/latest). Cada release contém:

- CardioAssistSigner-Windows-x64.exe
- CardioAssistSigner-macOS-arm64.dmg
- CardioAssistSigner-macOS-x64.dmg
- SHA256SUMS.txt
- release-manifest.json

Releases com official: false no manifesto são builds de teste não assinadas e podem gerar alertas do SmartScreen ou Gatekeeper. Somente releases com official: true foram assinadas e, no macOS, notarizadas.

Nunca envie arquivo PFX/P12, senha, PIN ou chave privada ao navegador, servidor, GitHub ou suporte. O certificado médico é usado somente pelo aplicativo instalado no computador do médico.
